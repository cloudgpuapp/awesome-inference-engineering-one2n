# Code of Conduct

We want contributions to be respectful, constructive and technical.

Be kind; debate ideas and technical evidence, not people. Avoid harassment, discrimination, personal attacks, spam and promotional flooding. Maintainers may edit, decline or remove content and participation that violates these expectations.

Report concerns privately to the repository maintainers via GitHub's reporting mechanisms. Before publication, configure a private contact method in the repository settings or replace this line with a project-specific reporting address.
